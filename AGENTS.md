## Language — Australian English

All English prose produced in this session — including responses, comments,
documentation, commit messages, and user-facing text — MUST use Australian
English spelling. Examples: behaviour (not behavior), colour (not color), centre
(not center), organisation (not organization), optimise (not optimize), prioritise,
labour, travelled, defence (not defense), programme, analogue. Do not use American
spellings. Code identifiers, external API names, and verbatim quotations are exempt.
